# Roadmap

1. Playtest the five-wave slice. Tune the economy and difficulty using breach counts, defender survival, and viable opening formations.
2. Improve combat readability and add original unit silhouettes, attack sounds, and placement previews.
3. Prototype one upgrade path per defender and a first era transition. Evaluate how each affects formation and spending decisions.
4. Add a second battlefield or wave set after the first match plays reliably.
5. Evaluate command serialization and replay determinism before prototyping a future authoritative multiplayer match.
