# Riftfront: Ages Under Siege

A single-player, three-lane tower defense prototype built with Phaser 4, TypeScript, and Vite.

```sh
npm install
npm run dev
```

Open the URL printed by Vite. Select a defender, choose an open pad, then start the wave. Reinforce between waves and keep the core standing through wave five.

```sh
npm test
npm run build
```

See [game design](docs/GAME_DESIGN.md) and the [roadmap](docs/ROADMAP.md).
